Desarrollo de una aplicación de consola para la gestión de alumnos y sus notas, centrándose en la persistencia de datos a través de cinco formatos distintos, manteniendo una única interfaz de operaciones (services).

Java POO JAXB Gson File I/O Lombok

Inventario Dinámico Temático (Android Nativo/Firebase) (2º DAM - Noviembre 2025)


Noviembre 2025

Proyecto individual – Aplicación Móvil en Kotlin

Tecnologías utilizadas: Kotlin, Android Nativo, Firebase Realtime Database,RecyclerView, ViewBinding, LayoutManager (Linear/Grid).
Desarrollo de una aplicación móvil para la gestión de un inventario temático ('Stranger Things'), demostrando la persistencia de datos en la nube, la eficiencia de la interfaz de usuario y la sincronización en tiempo real entre distintas pantallas.

Kotlin Android Firebase RecyclerView ViewBinding

Características Técnicas:

  • Implementación de Firebase Realtime Database para la lectura y escritura de datos asíncronos.
  • Arquitectura modular con separación de responsabilidades: una Activity para la entrada/escritura de datos y una segunda Activity dedicada exclusivamente a la visualización (lectura) de la lista.
  • Uso del componente RecyclerView con un adaptador personalizado para un renderizado eficiente de la lista de ítems.
  • Sistema de validación de entrada con catálogo que restringe los nombres de personajes aceptados y realiza autocompletado de objetos icónicos.
  • Implementación de lógica para manejo del Estado Vacío (Empty State) y ajuste automático del diseño (Vertical/Cuadrícula) según la orientación del dispositivo.
  • Diseño UX: Se asegura la confirmación visual al guardar mediante un sistema de retroalimentación inmediato y un diseño temático.
